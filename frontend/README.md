# Fase 3: Frontend & UI (Svelte 5, SvelteKit & TypeScript)

## Objetivo
Desarrollar la interfaz de usuario web para buscar y comparar precios de medicamentos.

## Estructura
- `src/routes/`: Rutas de la aplicación (páginas principales, ficha de producto).
- `src/lib/components/`: Componentes UI reutilizables (SearchBar, ProductCard, etc.).
- `tests/`: Pruebas End-to-End y tests de componentes.

## Tareas Clave
- **Barra de Búsqueda:** Búsqueda en vivo (debounce) de medicamentos.
- **Grilla de Resultados:** Mostrar comparativa de precios.
- **Ficha de Producto:** Detalle por medicamento y su historial de precios.
- **Storybook:** Documentar y probar componentes en aislamiento.
- **Playwright:** Asegurar flujos críticos (E2E).

## Instrucciones
- Utilizar Svelte 5 con SvelteKit.
- Tipado estricto con TypeScript.
- Conectar con la API del Backend (Fase 2).
